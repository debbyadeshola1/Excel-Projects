## 📊 Electronic Sales Dashboard (Excel Project)
### 📌 Project Overview

This project is an interactive Sales Performance Dashboard built in Microsoft Excel using a dataset of 15,001 sales records.

The dashboard provides insights into sales performance across:

- States (Regions)

- Sales Channels

- Product Categories

- Sub-Categories

- Order Date (Year-over-Year comparison)

It enables dynamic analysis of Top 10 and Bottom 10 states based on all-time revenue using advanced Excel functions.

## 🗂 Dataset

### Total Records: 15,001

Fields include:

- State

- Sales Channel

- Product Category

- Sub-Category

- Order Date

- Revenue

- Profit

## 📈 Key Analysis Performed

- Total sales by region (state)

- Sales performance by channel

- Sales trends by order date

- Product category performance

- Top selling sub-categories per category

- Top 10 and Bottom 10 states by all-time revenue

- Top 5 channels with highest revenue

## 🔎 Key Insights

1️⃣ Ebonyi State generated the highest all-time revenue.

2️⃣ The Store channel had the highest overall revenue.

3️⃣ Projectors and Screens was the best-selling sub-category under the Computers category.

4️⃣ There was a decline in total sales from 2013 to 2014.
